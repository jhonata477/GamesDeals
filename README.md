# 🎮 GameDeals - Comparador de Ofertas de Jogos

Aplicação web desenvolvida em React para consulta em tempo real de promoções e descontos de jogos de PC através da CheapShark API. O projeto conta com sistema de rotas, páginas de detalhes dinâmicas, salvamento de favoritos no `localStorage` e estilização moderna com Tailwind CSS.

## 🚀 Tecnologias Utilizadas

* **React (Vite)** - Biblioteca JavaScript para construção da interface de usuário.
* **Tailwind CSS** - Framework CSS utilitário para estilização rápida e moderna.
* **React Router DOM** - Gerenciamento de rotas e navegação SPA (Single Page Application).
* **CheapShark API** - API pública gratuita para consumo de dados de preços e ofertas de jogos.
* **LocalStorage** - Persistência local dos jogos favoritos do usuário.
